SECTION 01 · OVERVIEW & PHILOSOPHY

壹認識太玄三進制計算專案

「太玄三進制計算」（Tai Xuan Ternary Computing）是一套純前端的互動式教學模擬器，以 React、TypeScript 與 D3 建構，不需任何 API 金鑰即可完整運行。它做了兩件事的疊加：把西漢揚雄《太玄經》的三進制宇宙觀，作為一套真實可驗證的數字邏輯體系；再把經典課程《Nand to Tetris》的自底向上教學法，逐級移植到三值世界。使用者的旅程從一枚「元始 T-NAND 閘」開始——正如原課程一切邏輯都源於 NAND——隨後逐階合成基礎門、加法器、ALU、寄存器，最終組裝出一台能執行組合語言、驅動 9×9 顯示器、甚至運行方塊遊戲的八十一首微機。

「夫玄也，幽攡萬類而不見形者也。天以三分，地以三策，人以三軌……三三相乘，四重而成八十一首。」 —— 西漢 · 揚雄《太玄經》

揚雄（西元前 53 年－18 年）在《太玄經》中建立了一套完整的 三進制符號宇宙體系：以「方、州、部、家」四層結構，每層三值，三三相乘得 3⁴ = 81 首；每首九贊，全書共 729 贊，對應太初曆一年 365.25 日的分值體系。模擬器忠實保留了這套結構：一個 4-Trit 字的四個爻位分別命名為方（T3）、州（T2）、部（T1）、家（T0），數值即 T3×27 + T2×9 + T1×3 + T0，恰好落於 0–80，每一個取值都對應一首有名字、有節氣日期的卦象——首一「中」對應冬至初日，首八十一「終始之極」收束全週期。

這條思路在數學史上並非孤例。二進制一側有萊布尼茨與伏羲六十四卦的著名對照；三進制一側，高德納在《The Art of Computer Programming》第二卷中寫道：

"Perhaps the prettiest number system of all is the balanced ternary notation." —— Donald E. Knuth, TAOCP Vol.2（也許最美的記數法就是平衡三進制）

平衡三進制無需符號位與補碼即可表示負數，工程史上最著名的實踐是 1958 年莫斯科國立大學 Brusentsov 團隊建造的 Сетунь（Setun）計算機。模擬器的「太玄源流」彈窗完整鋪陳了這三段源流，而整個 T-NAND 體系正是對 Setun 精神的現代重演：以最少的完備原語，疊構出整座計算機。

Trit 三值編碼與三種顯示模式

體系的最小單位是 Trit（三值位），以天、地、人三才命名：天 ⚊ 為高電位（標準制 2、平衡制 +1）、地 ⚋ 為中電位（1 / 0）、人 𝌀 為低電位（0 / −1）。同一組訊號可以在三種顯示模式之間即時切換——太玄（天地人）以卦爻呈現、平衡（+1, 0, −1）便於算術推理、標準（2, 1, 0）貼近傳統數位電路表述。這個切換器位於頂部導覽列，是全站唯一的全域視角控制，建議初學者先停在太玄模式建立直覺，進入 ALU 章節後再切到平衡模式驗算。

SECTION 02 · CURRICULUM MAPPING

貳學習地圖：九階課程 × 八大階梯對照

經典《Nand to Tetris》把「從邏輯閘到電腦」拆成九個專案階段（硬體 01–06、虛擬機 07–08、高階語言 09）。本專案以「同構改編」的方式把它們映射到三進制世界：每一階都有一個太玄版的對應物，概念順序完全一致，但字寬、指令數與記憶體規模全部按三進制重新推導。本章末的對照表是全冊的總索引——建議把它當作學習進度表，每完成一個階梯就回來核對一次。先說明兩個使用原則：

對照原則：同構而非複刻

太玄版不是把原課程逐位元翻譯：機器字寬從 16-bit 改為 4-Trit（81 種取值），ALU 從 18 個控制位改為 9 個運算碼，主記憶體從 32K Word 改為 81 字 ROM。每個數字都由 3⁴ 自洽推出——理解這些「為什麼是 81」的推導，正是本專案最有趣的訓練。

給自學者的建議

已熟悉原課程者，可直接從「貳」的對照表進入感興趣的階梯；初學者建議按階梯 1→8 順序推進，每階先用互動元件操作、再讀手冊原理、最後回模擬器完成該階的自我檢核（見「拾壹」）。三個重點章節（參、肆、柒）值得精讀。

SECTION 03 · STAGES 1–3 · LOGIC GATES ● 重點章節

參階梯一至三：元始門與基礎門殿

對應課程 01 布林邏輯。二進制世界的一切邏輯都源於單一枚 NAND 閘——它是函數完備的（functionally complete）。太玄版同樣只欽定一枚完備元始門：T-NAND，標準三進制下定義為 T-NAND(A, B) = 2 − min(A, B)（平衡三進制下為 −min(A, B)）。兩輸入共 3×3 = 九種狀態，全部九態皆可由這一式推出：

A ＼ B人 (0)地 (1)天 (2)
人 (0)天天天
地 (1)天地地
天 (2)天地人

直覺口訣：任一端為人，輸出必為天（低電位拉高結果）；兩端皆天，輸出為人；其餘取「2 減去較小者」。階梯一提供 Trit 選擇器引腳與即時高亮真值表，每切換一次輸入，右側電路圖的訊號流便同步重繪；按下「執行自動合成驗證」，系統會窮舉九態核對公式，全數通過即撒出彩帶。

由一門生萬門：合成族譜與太玄德摩根律

基礎門殿（階梯二）示範如何只用 T-NAND 疊出整個邏輯門家族，並標出每個門的 T-NAND 成本：T-NOT 僅需 1 顆（T-NAND(A, A) = 2 − A）；T-AND（降取門，即 T-MIN）用 2 顆——雙重倒反消去 NAND 中的減法，還原為逐位取小；T-OR（升取門，即 T-MAX）用 3 顆，其推導就是三值版的太玄德摩根定律：T-OR(A, B) = T-NAND(T-NOT A, T-NOT B) = max(A, B)；T-NOR 則再串一顆倒反，共 4 顆。每個門的分頁都附雙輸入互動與九態真值表，可以親手驗證成本數字。

階梯三「選擇與特徵」再引入三個特徵門，它們在後續章節各司其職：T-MUX 3:1 三路選擇器——一個 trit 的天然三態正好選通三路（S 為人通道 d0、地通道 d1、天通道 d2），這是 ALU 選擇樹的基本積木；T-CYCLE 循變門——(a+1) mod 3，訊號沿人→地→天→人循環一周，是時序狀態機的狀態輪轉基礎；T-CONSENSUS 同契判定門——兩輸入相同輸出天、相異輸出人，是分支與比較邏輯的核心。

TaiXuan HDL：硬體描述語言

對應課程 01 的 HDL 部分，模擬器內建 TaiXuan HDL（T-HDL），語法與 Hack HDL 同構：CHIP 宣告、IN／OUT 埠、PARTS 區塊逐行佈線。檔案庫共六枚晶片，構成一條完整的依賴鏈——TNand（BUILTIN 原語）→ TNot → TAnd → TOr → THalfAdder → TAlu4。例如 TOr 的原始碼正是德摩根律的逐行落地： 

CHIP TOr {
    IN a, b;
    OUT out;
    PARTS:
    TNot(in=a, out=notA);
    TNot(in=b, out=notB);
    TNand(a=notA, b=notB, out=out);
}

在階梯八的 HDL 仿真器中選定晶片，系統會自動跑窮舉測試向量（相當於原課程的 .tst／.cmp 流程）；「太玄源流」的 HDL 檢視器則把六枚晶片的原始碼與依賴關係一次攤開，適合在讀完本章後對照複習。

SECTION 04 · STAGES 4–5 · ADDERS & ALU ● 重點章節

肆階梯四至五：算術與四爻 ALU

對應課程 02 布林運算。三進制的加法口訣是逢三進一：半加器把兩個 trit 相加，和取 sum = (a+b) mod 3，進位取 carry = ⌊(a+b) / 3⌋。介面給的第一個例子就很直觀：天(2) + 地(1) = 3 = (1, 0)₃——本位得人、進位得地。全加器再納入低位進位，最大輸入 2+2+2 = 6 = 20₃，本位 0、進位 2。

把四級全加器從家（T0，個位）到州、部逐級串到方（T3，最高位），就是四爻首加法器：四個 trit 恰好表達 81 首空間（0–80），漣波進位逐層上湧。階梯四的互動把 X、Y 四個爻位攤開成選擇器，即時輸出和的首象與進位，旁邊的流水線圖標示進位傳播路徑——這正是理解「為什麼乘三即左移」的實驗台。

4-Trit ALU：九種運算一次並行

階梯五把算術與邏輯收攏成一台 4-Trit ALU。它同時計算九種運算，再由三級 TMux3Way4 選擇樹按運算碼選出結果（opcode 在 HDL 抽象中為 3-trit 寬度）。在微機中，每個時鐘週期執行 Acc = ALU(Acc, Immediate, opcode)，即時數直接內嵌於 4-Trit 指令字。

SECTION 05 · STAGE 6 · MEMORY & TIMING

伍階梯六：記憶時序

對應課程 03 時序邏輯的前半：從組合邏輯跨入「有記憶的電路」。二進制以兩顆交叉耦合 NAND 構成雙穩態鎖存器；太玄版則以 三顆交叉耦合 T-NAND 構成「三穩態鎖存器」——三門環形反饋，恰好以三才鼎足之勢駐存天、地、人三種電位態，程式碼中的反饋式為： 

Q1 = T-NAND(Q2, Set1);   // 天位反饋
Q2 = T-NAND(Q3, Set2);   // 地位反饋
Q3 = T-NAND(Q1, Set3);   // 人位反饋

「天以三分，地以三策，人以三軌」——原典的宇宙論語句，在這裡成了一個具體的電路拓撲。三穩態單元是三值世界的基本記憶原子：只要不被打擾，它會永遠記住自己的那一爻。

4-Trit 主寄存器與時鐘邊緣寫入

把四個三穩態單元並聯，就是能鎖存任一首（0–80）的 4-Trit 主寄存器（累加器前身）。階梯六的互動提供完整的寫入時序訓練：先用四個 TritSelector 準備「待寫入資料匯流排」，勾選 Write Enable 使能寫入，再按下「觸發時鐘上升沿」——資料只在時鐘邊緣被鎖進寄存器，介面同時計數時鐘週期（#clockTick）；「復位」按鈕則把寄存器清回全地狀態。反覆操作幾次，就能體會「使能 × 時鐘」這對組合如何隔離資料準備與資料寫入兩個階段，這是所有同步電路的根基。

課程安排上，本章刻意止步於寄存器：大容量記憶體不在這裡鋪開，而是於階梯七以「81 字 ROM + 9×9 顯存」的映射形式登場，FPGA 章節再落實為 81×2-bit 雙端口 VRAM 硬體。這與原課程把 RAM 細分多個專案的節奏不同，但「先鎖存、後匯流、再記憶體」的認知階梯是一致的。

SECTION 06 · STAGE 7 · THE MICRO-MACHINE

陸階梯七：八十一首微機

對應課程 05 計算機架構。把前五階的成果——ALU、寄存器、顯存——總裝起來，就是「太玄八十一首微機」：一台字寬 4-Trit、記憶空間 81 首的完整計算機。它的 CPU 極簡而自洽：一個程式計數器 pc、一個 4-Trit 累加器 acc（初值 [1,1,1,1]，即第 40 首「中」位）與一個時鐘計數器。每個時鐘週期執行 Acc = ALU(Acc, Immediate, opcode)，程式計數器循環回繞，程式便永續運行。

章節內劃分為五個子視圖，構成一台完整機器的五個切面：

  • 微機流水線主控台——架構與資料通路總覽：程式計數器與譯碼器 → 4-Trit ALU 核心（Acc ⊛ Immediate）→ 四爻累加器 → 外設顯存與鍵盤 I/O。內建三支示範程式：太玄三進制斐波那契數列、八十一首歲時曆法巡曆、天地人三元平衡求解器，另有彙編燒錄的自訂程式。
  • 卦象譜系瀏覽器——81 首即記憶位址：點擊任意首，直接把該首載入記憶分佈與暫存器配置，把「資料」與「卦象」二合一的記憶體觀點可視化。
  • 顯存與鍵盤終端——9×9 顯存映射 @0x30–0x4E 共 81 個三值光點，鍵盤映射 @0x4F；附畫筆與橡皮，可手動繪製再交給程式處理。
  • 符號彙編與 ROM 燒錄——完整組合語言 IDE，下章專述。
  • 終章巨獻・太玄三象方塊——結業遊戲，見「捌」。

流水線主控台的核心是 Trace Console 執行日誌：機器每拍一行，完整吐出時鐘序號、PC、指令與運算後的首象，例如： 

[時鐘 #1] PC=0  | 指令: ADD | 運算後首象: 【中】第1首 (冬至初日)
[時鐘 #2] PC=1  | 指令: SET | 運算後首象: 【羨】第2首  // …

控制列提供「自動運行」（900ms 間隔）、「單步時鐘」與「復位」。初學者建議先單步走完一輪斐波那契，對照 Trace 逐行讀懂 Acc 的變化；熟悉後再切自動模式，觀察 81 首歲時曆如何以 mod 81 的方式巡曆一整個「玄年」。

SECTION 07 · STAGE C · ASSEMBLER ● 重點章節

柒太玄彙編器：從符號到機器碼

對應課程 06 彙編編譯器。「太玄符號彙編器與微機 ROM 燒錄台」（Stage C 專項工程）把人類可讀的組合語言翻譯成微機可執行的三值機器碼。它採用與經典兩遍掃描（Two-Pass）彙編器完全一致的架構：第一遍逐行掃描，建立符號表——記下每個標籤的位址，供前向引用回填；第二遍逐行編碼，把每條指令輸出為「首序號 + 運算碼 + 4-Trit 即時數」，同時附上十六進位碼與「地地地人」式的三值字串。編譯結果可匯出 .txa 檔，或直接按下「燒錄至微機 ROM」送進階梯七的流水線執行。

語法五要素

定向與標籤

.ORG 0x00 設定起始位址；標籤寫作 LABEL: 或 @LABEL:，支援中文標籤（如 震盪迴圈:），正則允許中文字元直接作為符號名。

五類操作數

十進位 #42／42；十六進位 0x2A／@0x4F；三值字面 %2101 或直接寫「天天地人」（不足四位左補地）；標籤引用 @LOOP；以及 81 首名直接當操作數——【中】 即數值 40。

註解以 // 或 ; 起頭。ROM 總容量為 81 字——這不是隨意的限制，而是 4-Trit 位址空間的自然邊界；程式超出時彙編器會給出「地址溢出警告」。

助記符 ↔ 首序對應：指令集即卦序

太玄機器碼最優雅的設計在於：每條指令的運算碼本身就是一個首序號。NOP 是首 1「中」，ADD 是首 2「羨」，HALT 是首 81「養」——指令集與 81 首卦序完全同構，22 條助記符各有別名（如 ADD / T_ADD），下表按功能分組：

助記符（別名）對應首功能
NOP首 1 · 中空操作，immediate 為全地 [1,1,1,1]
SET / MOV首 3 · 睟把即時數載入累加器
ADD首 2 · 羨Acc ← Acc + 即時數（mod 81 空間）
SUB首 11 · 窮Acc ← Acc − 即時數
MIN / AND / T_AND首 30 · 密逐爻降取（三值「與」）
MAX / OR / T_OR首 28 · 裝逐爻升取（三值「或」）
NOT / NEG / T_NOT首 81 · 養逐爻倒反
CYCLE / CYC首 41 · 文逐爻循變（+1 mod 3）
SHL首 5 · 達左移一位（乘三）
SHR首 4 · 斂右移一位（除三）
CMP首 7 · 視與即時數比較，置四大旗標
LOAD首 17 · 進自 RAM 位址載入累加器
STORE首 16 · 守把累加器存入 RAM 位址
IN.KBD / KBD.IN首 49 · 減讀入鍵盤掃描碼（位址 0x4F）
OUT.VRAM / VRAM.OUT首 39 · 大寫出顯存（基址 0x30）
OUT.PX x, y首 40 · 廓在 9×9 畫布 (x, y) 點亮一像素，位址 = 0x30 + (y mod 9)×9 + (x mod 9)
CLS.VRAM首 18 · 釋全屏清屏（鋪設地爻底色）
JMP / GOTO首 25 · 更無條件跳躍至標籤
JZ首 55 · 止地歸旗標（零）成立時跳躍
JNZ首 56 · 堅地歸旗標不成立時跳躍
JP首 37 · 遇陽昇（正值）時跳躍
JN首 59 · 苦人伏（負值）時跳躍
HALT首 81 · 養停機，immediate 為全人 [0,0,0,0]

內建範例：九宮顯存初始化與太極畫點

彙編 IDE 預載的範例程式 vram_clear_draw 只有十餘行，卻完整示範了清屏、配色、定點繪製與停機的全部生命週期。注意 SET #2 之後 OUT.PX 便以當前累加器值為顏色——「天爻」畫出金光亮點、「人爻」畫出赤朱： 

// 太玄顯存繪圖演示程式 (VRAM Demo)
// 顯存映射空間：@0x30 ~ @0x4E (81 個三進制光點)
.ORG 0x00
INIT:
  CLS.VRAM #1         // 1. 全屏清屏：鋪設「地爻」玄黑底色
  SET #2              // 2. 累加器載入純陽「天爻」(+1 / 金光)
  OUT.PX 4, 4         // 3. 在 9x9 畫面幾何中心 (4,4) 點亮太極中樞

CORNER_TIAN:
  SET #2              // 4. 四角天位配置
  OUT.PX 0, 0         // 左上乾位
  OUT.PX 8, 8         // 右下坤位

CORNER_REN:
  SET #0              // 5. 赤朱「人爻」(-1 / 赤朱)
  OUT.PX 0, 8         // 左下
  OUT.PX 8, 0         // 右上

HALT:
  NOP                 // 程式運行完成，保持當前顯存狀態

另有四套內建範例可供逐套研讀：鍵盤輪詢與光標實時移動（IN.KBD 搭配 CMP／JZ 分支）、太玄俄羅斯方塊引力內核（CYCLE 與條件跳躍構成的重力迴圈）、太玄四爻斐波那契演化（mod 81 空間的遞推）與天地人三才極性震盪器（NOT／CYCLE 交替的永續震盪）。建議的練習路徑：先單步執行本例，再修改 OUT.PX 的座標畫出自己的圖案，最後燒錄進微機看它跑起來。

SECTION 08 · STAGE A · CAPSTONE TETRIS

捌終章：太玄三象方塊

對應課程 09 高階語言應用。原課程以物件導向語言 Jack 撰寫《俄羅斯方塊》作為結業應用；太玄版的答案是「太玄三象方塊」（Stage A）——一座 9×12 棋盤（頂部 3 列緩衝、下方 9 列恰為 9×9 = 81 個顯存格）上的完整方塊遊戲，由 8 種「卦象方塊」組成：太玄一字（I）、三才鼎足（T）、乾坤中土（O）、玄宮曲折（L）、玄序反曲（J）、陰陽互錯（S）、天象變微（Z）與三爻神微（Tri-Trit），各自帶 4-Trit 著色圖樣。

消行規則是本作最獨創的設計，把三進制的三值性直接寫進了計分：

① 全行填滿消行

當 9 格顯存任意三值電位完全填滿時消除，基礎賦 100 分——這是所有方塊遊戲共通的底層規則。

② 三才同契大消除

被消除的行中若含相鄰的 {天, 地, 人} 三才組合，額外 +300 × level，並彈出「三才同契！天地人共融消除」的賀辭——鼓勵玩家刻意經營三色相鄰。

③ 純一玄化暴擊

整行同色（純天、純地或純人）消除時給予 3 倍暴擊——單一極性貫通整行，即「純一玄化」。

重力天階與首象映射

level = min(9, ⌊消行數/2⌋ + 1)，即「重力天階 第 N 天」；當前積分即時映射為首象 (score mod 81) + 1，分數本身就是一枚卦象。最高分存於瀏覽器 localStorage。

操作面：方向鍵或 WASD 移動與旋轉、空白鍵急墜、C 存卦（暫存區）、P 暫停。音效由 Web Audio 即時合成——移動用三角波、旋轉用正弦波，三才同契時奏出宮商角徵羽五聲音階的三才和弦（261.6 / 329.6 / 392 / 523.2 / 659.2 Hz）。介面右側同步展示 CPU 流水線即時遙測：PC（十六進）、IR（IN.KBD／SCAN_TRINITY 等指令名）與 ACC 四爻徽章，讓玩家看見「遊戲」之下那台微機的每一次心跳。

遊戲本身也附一份「TETRIS.TXA — 太玄虛擬機彙編程序核心」抽屜文件，展示遊戲迴圈的組織骨架：MAIN_INIT → GAME_LOOP → PROCESS_INPUT → TICK_GRAVITY → LOCK_PIECE → SCAN_TRINITY，其中可見 IN.KBD、CALL CHECK_COLLIDE、SPAWN R_NEXT 等擬似指令——它既是文件，也是給學生的改寫藍本：讀懂這六段，你就讀懂了一台三值遊戲機的靈魂。

SECTION 11 · LEARNING PATH & CHECKLIST

拾壹建議學習路徑與自我檢核

最後給出一條可執行的學習路徑。它把八大階梯分為三段，每段都以上一段的產出為輸入；每階末尾的自我檢核通過後再進入下一階，比「讀完再練」紮實得多。

初階 · 階梯一至三（元始門 → 選擇與特徵）

目標：建立三值直覺，掌握完備性思想。搭配工具：互動真值表生成器、HDL 仿真器。

  • 能徒手寫出 T-NAND 的 3×3 九態真值表，並用一句話解釋「為何任一端為人輸出必為天」。
  • 能說出 T-NOT／T-AND／T-OR／T-NOR 各需幾顆 T-NAND，並推導太玄德摩根律。
  • 在模擬器中切換三種顯示模式，確認同一訊號在「天 / +1 / 2」三制下的對應關係。
  • 在 HDL 仿真器中跑通 TOr 的窮舉測試，讀懂每一行 PARTS 佈線。

中階 · 階梯四至六（算術 → 記憶時序）

目標：從組合邏輯跨入時序邏輯，建立「逢三進一」的算術手感。搭配工具：三值時序分析儀、動態時序模擬。

  • 手算 2+1 = 10₃ 與 2+2+2 = 20₃，指出和與進位各是哪一爻。
  • 用四爻加法器計算 40+40，觀察溢出旗標；解釋 SHL 為何等價於乘三。
  • 在 ALU 中逐一試九個運算碼，記錄每個運算的旗標變化。
  • 用「Write Enable × 時鐘上升沿」把一個首象寫入寄存器，並說明兩者缺一不可的原因。

高階 · 階梯七至八（微機 → 工作台）＋ FPGA

目標：讀懂一台完整的機器，並動手改寫它的程式。搭配工具：彙編 IDE、單元測試台、ALU 延遲熱點圖。

  • 單步跑完斐波那契程式，對照 Trace Console 說出每拍 Acc 與首象的變化。
  • 修改「九宮顯存初始化與太極畫點」，畫出自己的圖案並燒錄至 ROM 執行。
  • 讀懂 TETRIS.TXA 的六段遊戲迴圈骨架，指出三才同契判定發生在哪一段。
  • 在測試台注入一個故障（faultInjection），用逐爻診斷報告定位出錯爻位。
  • （選做）在 DE2 上完成五步燒錄，用 SW17 切換 CPU 寫入模式並以 SW9:2 注入指令。
