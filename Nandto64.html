第一章　導論：兩種生成邏輯的相遇

「易有太極，是生兩儀，兩儀生四象，四象生八卦，八卦定吉凶，吉凶生大業。」——《易傳·繫辭上》
「電腦科學不是關於電腦的科學，而是關於計算的科學。它研究的是：什麼是可計算的，以及如何計算。」——Michael Sipser

這本書試圖回答一個看似不可能的問題：

一台從 Nand 閘開始建構的電腦，和一套從陰陽爻開始推演的易經卦象，它們之間有什麼關係？

答案是：它們共享同一種生成邏輯。

  • 兩者都從最簡單的元素出發（Nand 閘 / 陰陽爻）
  • 兩者都透過組合與封裝向上建構（邏輯閘 → ALU → CPU / 四象 → 八卦 → 六十四卦）
  • 兩者都從靜態結構演化為動態執行（組合邏輯 → 時序邏輯 / 卦象 → 卦變）
  • 兩者都透過命名與編碼賦予意義（指令集 / 卦辭爻辭）

1.1 Nand2Tetris 是什麼

Nand2Tetris（又名《The Elements of Computing Systems》）是以色列理工學院（Technion）的 Shimon Schocken 和 Noam Nisan 教授於 2005 年開設的課程。

課程的核心理念是：

「從一個 Nand 閘開始，建構一台完整的電腦。」

這門課拒絕「黑箱」——學生不會被告訴「CPU 就是這樣運作的」，而是要親手用 Nand 閘建構出 CPU。

  3. 動手實作（Hands-On）：每個元件都要親手實作，通過測試才能進入下一章

3.1 技術層：Nand 閘與基本邏輯閘

3.1.1 Nand 閘：通用閘

Nand 是「Not And」的縮寫，它的真值表如下：

abNand(a, b)
001
011
101
110

Nand 的特性：

  • 只有當兩個輸入都為 1 時，輸出才為 0
  • 其餘所有情況，輸出都為 1

為什麼 Nand 是通用閘：

因為任何布林函數都可以用 Nand 閘實現。這意味著：

  • Not、And、Or、Xor 都可以用 Nand 實現
  • 所有更複雜的電路（ALU、CPU）也可以用 Nand 實現
  • Nand 是數位邏輯的「原子」

3.1.2 由 Nand 建構的基本邏輯閘

Not 閘：

用 Nand 實現：Not(a) = Nand(a, a)

9.1.5 函數呼叫機制

呼叫流程（call f n）：

1. 將返回位址推入堆疊
2. 將當前的 LCL, ARG, THIS, THAT 推入堆疊
3. 設定 ARG 為新的參數區
4. 設定 LCL 為新的局部變數區
5. 跳躍到函數 f 的位址

返回流程（return）：

1. 將返回值放到 ARG[0]
2. 恢復 LCL, ARG, THIS, THAT
3. 跳躍到返回位址

class Meihua {
    field int yao1, yao2, yao3, yao4, yao5, yao6;
    field int movingYao;
    field int originalBinary;
    field int changedBinary;
    
    constructor Meihua new() {
        let yao1 = 0;
        let yao2 = 0;
        let yao3 = 0;
        let yao4 = 0;
        let yao5 = 0;
        let yao6 = 0;
        let movingYao = 0;
        let originalBinary = 0;
        let changedBinary = 0;
        return this;
    }
    
    method void cast(int num1, int num2, int num3) {
        var int upper, lower, upperBagua, lowerBagua;
        let upper = num1 - (num1 / 8 * 8);
        if (upper = 0) { let upper = 8; }
        let lower = num2 - (num2 / 8 * 8);
        if (lower = 0) { let lower = 8; }
        let movingYao = num3 - (num3 / 6 * 6);
        if (movingYao = 0) { let movingYao = 6; }
        let upperBagua = getBaguaBinary(upper);
        let lowerBagua = getBaguaBinary(lower);
        let yao1 = lowerBagua & 1;
        let yao2 = (lowerBagua >> 1) & 1;
        let yao3 = (lowerBagua >> 2) & 1;
        let yao4 = upperBagua & 1;
        let yao5 = (upperBagua >> 1) & 1;
        let yao6 = (upperBagua >> 2) & 1;
        let originalBinary = (yao6 * 32) + (yao5 * 16) + (yao4 * 8) + (yao3 * 4) + (yao2 * 2) + yao1;
        let changedBinary = originalBinary;
        if (movingYao = 1) { let changedBinary = changedBinary ^ 1; }
        if (movingYao = 2) { let changedBinary = changedBinary ^ 2; }
        if (movingYao = 3) { let changedBinary = changedBinary ^ 4; }
        if (movingYao = 4) { let changedBinary = changedBinary ^ 8; }
        if (movingYao = 5) { let changedBinary = changedBinary ^ 16; }
        if (movingYao = 6) { let changedBinary = changedBinary ^ 32; }
        return;
    }
    
    method int getBaguaBinary(int num) {
        if (num = 1) { return 7; }
        if (num = 2) { return 6; }
        if (num = 3) { return 5; }
        if (num = 4) { return 4; }
        if (num = 5) { return 3; }
        if (num = 6) { return 2; }
        if (num = 7) { return 1; }
        if (num = 8) { return 0; }
        return 0;
    }
    
    method void draw() {
        do Output.printString("本卦：");
        do Output.printString(HexagramNames.getName(originalBinary));
        do Output.println();
        do HexagramDisplay.drawHexagram(originalBinary, 100, 100);

        do Output.printString(HexagramNames.getName(changedBinary));
        do Output.println();
        do HexagramDisplay.drawHexagram(changedBinary, 300, 100);
        return;
    }
}

這本書的寫作緣起於一個簡單的問題：
